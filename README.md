# Електронний термометр на модулі ESP8266
## Короткий опис
Електронний термометр показує поточну температуру в реальному режимі часу, відображає графік зміни температури. Прилад може використовуватись під час шкільних лабараторних робіт, проведеня дослідів, та в побуті. Для візуалізації отриманих значень температури використовується компютер або телефон з WIFI. 
## Склад приладу
Прилад побудований на основі мікронтролера ESP-8266 та датчика температури DS18B20.
## Під'єднання до приладу
Після ввімкненя та завантаженя wifi мережі повина з'явитись нова точка доступу з назвою ESP-Sensor (пароль 12345678). В адресному рядку браузера треба ввести адресу 192.168.4.1. Після цього в браузері повинен завантажитись графік і значення поточної температури.
